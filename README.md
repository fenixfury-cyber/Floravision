# FloraVision

FloraVision is a concept for a modern floral point-of-sale and operations platform built around how flower shops actually work: fast-moving orders, freestyle design, delivery accountability, and inventory uncertainty.

This repository starts with:

- A product brief extracted from the source conversation
- A lightweight responsive prototype UI
- A roadmap for the next implementation slices

## Project Direction

Core principles:

- Search-first navigation instead of nested menu hunting
- Mobile-friendly workflows for shop floor, cooler, and drivers
- Inventory support for freestyle floral design, not rigid recipes
- Elegant, contemporary, slightly whimsical presentation
- Strong reporting, accountability, and proof-of-delivery

## Files

- `docs/product-brief.md`: product definition and MVP scope
- `index.html`: first interactive prototype shell
- `styles.css`: visual system and responsive layout
- `app.js`: demo interactions

## Open Locally

Open `index.html` in a browser.
